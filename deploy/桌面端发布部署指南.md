# 深瞳AI 桌面端发布部署指南

## 服务器架构

```
Docker nginx 容器 (shentong-nginx)
  └─ /opt/shentong/updates/  →  /usr/share/nginx/html/desktop  (ro 只读挂载)
     └─ ShenTongAI-Setup-x.x.x-x64.exe          (electron-updater 自动更新用)
     └─ ShenTongAI-Setup-x.x.x-x64.exe.zip      (用户官网下载用，服务器端自动压缩)
     └─ latest.yml

访问地址: https://zt.shentongapi.cn/desktop/latest.yml
```

**关键：上传目标目录是 `/opt/shentong/updates/`，不是 `/usr/share/nginx/html/desktop/`**

## 现行方案：GitHub Actions CI 构建发布（已验证）

> 触发工作流：`.github/workflows/desktop-build.yml`
> 触发条件：push 到 `upgrade/electron-41` 且改动涉及 `desktop/**`（或推送 `desktop-v*` tag）
> 版本机制：**CI 自动进位**——读取 package.json 版本 patch+1（1.1.3 → 1.1.4），只用于本次构建，不回写仓库。无需手动改版本号。
> 注意：若上次发布后未把 package.json 同步进位，需先手动 +1，否则 CI 会构建出与线上重复的版本号（例如线上已 1.1.3、package.json 仍 1.1.2 时，需先改成 1.1.3，CI 才能构建 1.1.4）。


### 第 1 步：本地提交并推送（Windows PowerShell）

系统未安装 git，使用 codex 运行时捆绑的 git：

```powershell
$git = "C:\Users\Administrator\.cache\codex-runtimes\codex-primary-runtime\dependencies\native\git\cmd\git.exe"
# 注意：必须带 & 调用符
& $git add -- <改动文件...>
& $git commit -m "feat/fix(desktop): 改动说明（版本1.1.3，CI构建1.1.4）"
# 推送：main 保持主干同步；upgrade/electron-41 触发 CI 构建
& $git push https://github.com/eladialance-cloud/zt.shentongapi.cn.git main
& $git push https://github.com/eladialance-cloud/zt.shentongapi.cn.git main:upgrade/electron-41
```

提交信息里按惯例标注 "版本X，CI构建Y"，便于对照。

### 第 2 步：等待构建并下载安装包

从上一版下载脚本复制模板，替换版本号生成 `D:\二次开发\download-X.Y.Z.ps1`：

```powershell
# 模板：download-1.1.3.ps1 → download-1.1.4.ps1（只改 $DL 里的版本号）
powershell -ExecutionPolicy Bypass -File D:\二次开发\download-1.1.4.ps1
# 脚本逻辑：轮询 GitHub Actions API（最长 40 分钟）→ 成功后下载 windows artifact
# 到 D:\二次开发\desktop-artifact\1.1.4\（含 ShenTongAI-Setup-1.1.4-x64.exe、latest.yml）
```

### 第 3 步：上传到服务器

```powershell
scp "D:\二次开发\desktop-artifact\1.1.4\ShenTongAI-Setup-1.1.4-x64.exe" "D:\二次开发\desktop-artifact\1.1.4\latest.yml" ubuntu@129.204.227.200:/tmp/
```

### 第 4 步：服务器发布（SSH 登录后粘贴执行）

```bash
cd /opt/shentong/updates
sudo cp latest.yml latest.yml.bak.$(date +%Y%m%d%H%M%S) 2>/dev/null || true
sudo rm -f ShenTongAI-Setup-*.exe ShenTongAI-Setup-*.exe.zip
sudo mv /tmp/ShenTongAI-Setup-1.1.4-x64.exe /tmp/latest.yml /opt/shentong/updates/
sudo zip -j ShenTongAI-Setup-1.1.4-x64.exe.zip ShenTongAI-Setup-1.1.4-x64.exe
sudo chown -R www-data:www-data /opt/shentong/updates/
# 验证（应显示 version: 1.1.4，且 .exe.zip 返回 HTTP 200）
curl -s https://zt.shentongapi.cn/desktop/latest.yml | head -3
curl -sI https://zt.shentongapi.cn/desktop/ShenTongAI-Setup-1.1.4-x64.exe.zip | head -3
```

### 第 5 步：后端部署（仅当提交涉及 backend/** 时）

```bash
cd /opt/shentong && sudo git pull origin main
cd backend && sudo rm -rf dist && sudo npm run build 2>&1 | tail -3 && echo BUILD_OK
sudo pkill -9 -f "node dist/main.js"; sleep 2
sudo bash -c "cd /opt/shentong/backend && nohup node dist/main.js > server.log 2>&1 &"
sleep 8 && curl -s http://127.0.0.1:3001/api/health; echo
sudo grep -iE "Startup migration failed|Startup migrations completed" /opt/shentong/backend/server.log | tail -5
```

## 完整自动化脚本（备用）

将以下脚本保存为 `D:\二次开发\desktop\scripts\publish.ps1`：

```powershell
# publish.ps1 - 一键打包+上传+部署
# 用法: .\scripts\publish.ps1 -ServerUser ubuntu -ServerHost 129.204.227.200 -RemoteDir /opt/shentong/updates

param(
    [string]$ServerUser = "ubuntu",
    [string]$ServerHost = "129.204.227.200",
    [string]$RemoteDir = "/opt/shentong/updates"
)

$ErrorActionPreference = "Stop"
Set-Location "$PSScriptRoot\.."

# 1. 读取版本号
$pkg = Get-Content "package.json" | ConvertFrom-Json
$version = $pkg.version
Write-Host "`n📦 版本号: $version" -ForegroundColor Cyan

# 2. 类型检查
Write-Host "`n🔍 TypeScript 类型检查..." -ForegroundColor Yellow
npm run typecheck
if ($LASTEXITCODE -ne 0) { Write-Host "❌ 类型检查失败" -ForegroundColor Red; exit 1 }

# 3. 构建
Write-Host "`n🔨 构建中..." -ForegroundColor Yellow
npm run build
if ($LASTEXITCODE -ne 0) { Write-Host "❌ 构建失败" -ForegroundColor Red; exit 1 }

# 4. 打包
Write-Host "`n📦 打包 electron-builder..." -ForegroundColor Yellow
npx electron-builder --win
if ($LASTEXITCODE -ne 0) { Write-Host "❌ 打包失败" -ForegroundColor Red; exit 1 }

# 5. 生成 latest.yml
Write-Host "`n📝 生成 latest.yml..." -ForegroundColor Yellow
npx tsx scripts/generate-latest-yml.ts

# 6. 找到安装包
$installer = Get-ChildItem "dist/installer" -Filter "ShenTongAI-Setup-$version-x64.exe" | Select-Object -First 1
if (-not $installer) {
    Write-Host "❌ 找不到安装包 ShenTongAI-Setup-$version-x64.exe" -ForegroundColor Red
    exit 1
}

$ymlFile = "dist/installer/latest.yml"
if (-not (Test-Path $ymlFile)) {
    Write-Host "❌ 找不到 latest.yml" -ForegroundColor Red
    exit 1
}

Write-Host "`n✅ 打包完成:" -ForegroundColor Green
Write-Host "   安装包: $($installer.Name) ($([math]::Round($installer.Length/1MB, 2)) MB)"
Write-Host "   清单:   latest.yml"

# 7. 上传到服务器 /tmp/
Write-Host "`n📤 上传到服务器..." -ForegroundColor Yellow
scp $installer.FullName "${ServerUser}@${ServerHost}:/tmp/"
scp $ymlFile "${ServerUser}@${ServerHost}:/tmp/"

# 8. 远程部署
Write-Host "`n🚀 远程部署..." -ForegroundColor Yellow
$remoteCmd = "sudo rm -f $RemoteDir/* && sudo cp /tmp/$($installer.Name) $RemoteDir/ && sudo cp /tmp/latest.yml $RemoteDir/ && echo '✅ 部署完成' && curl -s https://zt.shentongapi.cn/desktop/latest.yml | head -5"
ssh "${ServerUser}@${ServerHost}" $remoteCmd

Write-Host "`n🎉 发布完成！版本 $version 已上线。" -ForegroundColor Green
Write-Host "   验证地址: https://zt.shentongapi.cn/desktop/latest.yml" -ForegroundColor Cyan
```

## 常用排查

- 推送后 CI 没触发：确认本地提交已真正推到远端（`git ls-remote ... upgrade/electron-41` 应显示最新 commit），只推 main 不会触发构建
- 版本号进位异常：CI 自动 patch+1，patch ≥ 9 时进位 minor（如 0.6.9 + 1 → 0.7.0）
- 安装包下载失败：等 CI 构建 success 后再跑 download 脚本；GitHub 令牌通过 `git credential fill` 获取
- 新用户装完仍提示缺运行时：确认升级包未清空 `userData\runtime`（历史 bug 已修复）
