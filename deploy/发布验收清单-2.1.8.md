# 2.1.8 发布验收清单（素材库页收敛为「单层 · 两库」）

> 纯桌面端改动：后端代码与数据库结构**未变**，无需后端部署。
> 发布脚本：`powershell -ExecutionPolicy Bypass -File deploy\release-desktop.ps1 -Version 2.1.8 -Push -Publish`
> （遵循 `deploy/DESKTOP-RELEASE-SOP.md`；官网登记 SQL = `deploy/publish-2.1.8.sql`）

## 一、为什么改

用户反馈：素材库页套了**两层 Tab**，看着重复、页面乱。

| 层级 | 内容 |
|------|------|
| 外层（页面级 Tabs） | 素材库 / 合成视频 / 形象视频 / 音频素材 / 知识库 |
| 内层（素材库 Tab 里） | 用户输入库 / 生成素材库 |

判定：**外层后 4 项与内层是同一批 `media_assets`**，属重复入口。

| 被删入口 | 它实际是什么 | 现在去哪里 |
|----------|--------------|------------|
| 合成视频 | `listOralWorkshopJobs` 里筛 `videoUrl`（口播工坊成片） | 生成素材库 · 视频（可预览/下载）；任务视角在「口播工坊」 |
| 形象视频 | 输入库 `kind=avatar`（`media_assets` + `media_asset_avatar`） | 用户输入库 · 形象；**创建**在「口播工坊」我的形象 / 上传视频建形象 |
| 音频素材 | 输入库 `kind=voice`（`biz_type=voice_asset`） | 用户输入库 · 声音；**创建**在「口播工坊」声音克隆 |
| 知识库 | `listKnowledgeBases` 只读聚合 | 左侧菜单「知识库」独立入口（`/knowledge`，可增删文档与检索） |

结论：素材库页现在**只有一层** —— 用户输入库 / 生成素材库（类别是这一层下的二级过滤）。

## 二、改了什么

- `desktop/src/pages/Assets/index.tsx`：去掉页面级 `Tabs`，只渲染两库本体（单层）。
- 删除：`Assets/tabs.ts`、`Assets/panels/{ComposeTab,DigitalTab,AudioTab,KnowledgeTab}.tsx`、`Assets/panels/shared.ts`。
- `desktop/src/pages/Assets/AssetLibrary.tsx`：素材详情弹窗新增「下载」，保住被删面板里仅有的下载能力。
- `desktop/tests/unit/asset-page-tabs.test.ts`：由「恰好 5 个 Tab」改为**结构守卫** ——
  只允许一层、禁止再出现重复面板/文案、断言废弃文件已删除。

## 四、手工验收（真机）

1. 左侧「素材库」→ 页面**只有一层 Tab**：用户输入库 / 生成素材库。顶部标题下方不再出现「合成视频 / 形象视频 / 音频素材 / 知识库」。
2. 输入库二级类别含 图片/视频/音频/声音/形象/IP 档案/文档；生成库含 文案/图片/视频/音频。
3. 在输入库上传一张图片 → 出现在「输入库 · 图片」。
4. 点任一素材 → 详情弹窗：视频/音频可直接播放，且有「下载 / 复制链接 / 归档 / 加入语义索引」。
5. 口播工坊跑一条任务到出片 → 「生成库 · 视频」能看到该成片（自动入库，来源标注）。
6. 口播工坊建形象 / 声音克隆 → 「输入库 · 形象 / 声音」能看到（两处不是各存一套）。
7. 左侧「知识库」入口照常可用（增删文档、检索）。
8. 回归：画中画待用队列、口播工坊「素材与混剪」取素材仍正常。
